# OCR 默认牌面模板

这些 PNG 来自
[FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles)，
作者将全部素材置于公共领域（CC0）。许可原文见同目录 `LICENSE.md`。

默认模板适合识别相同或接近的电脑牌面风格。不同游戏皮肤可以替换此目录，
文件名必须使用：

- `Man1.png` ～ `Man9.png`
- `Pin1.png` ～ `Pin9.png`
- `Sou1.png` ～ `Sou9.png`
- `Ton.png`、`Nan.png`、`Shaa.png`、`Pei.png`
- `Haku.png`、`Hatsu.png`、`Chun.png`

可选赤五模板：`Man5-Dora.png`、`Pin5-Dora.png`、`Sou5-Dora.png`。
每张图片应只包含一张正置麻将牌，建议使用透明或纯色背景。
